# Foundations of Cybersecurity — Completed Learning Path

> A completed, end-to-end cybersecurity foundation curriculum documenting core concepts, applied knowledge, and job-aligned skills.

This repository consolidates notes, exercises, and applied artifacts from a comprehensive multi-course cybersecurity program.  
It serves as a **reference, knowledge base, and portfolio foundation** for entry-level and early-career cybersecurity roles.

---

## 📚 Curriculum Overview

### 1. Foundations of Cybersecurity
- Core security principles (CIA Triad)
- Security domains and career paths
- Ethics, laws, and governance
- Defensive mindset and attacker perspective

---

### 2. Play It Safe: Manage Security Risks
- Risk identification and assessment
- Threat modeling fundamentals
- Risk mitigation strategies
- Security controls and frameworks

---

### 3. Connect and Protect: Networks and Network Security
- Network architecture and protocols
- Firewalls, segmentation, and access control
- Common network-based attacks
- Defense-in-depth strategies

---

### 4. Tools of the Trade: Linux and SQL
- Linux command-line operations
- File permissions and process management
- SQL querying for security analysis
- Log and data investigation techniques

---

### 5. Assets, Threats, and Vulnerabilities
- Asset classification and valuation
- Threat actors and attack vectors
- Vulnerability identification and prioritization
- Exposure and impact analysis

---

### 6. Sound the Alarm: Detection and Response
- Security monitoring concepts
- Logging and alerting fundamentals
- Incident response lifecycle
- Detection vs response tradeoffs

---

### 7. Automate Cybersecurity Tasks with Python
- Python fundamentals for security use cases
- Automation of repetitive security tasks
- Basic data parsing and analysis
- Security-oriented scripting mindset

---

### 8. Put It to Work: Prepare for Cybersecurity Jobs
- Translating skills into resume language
- Portfolio development strategy
- Interview preparation fundamentals
- Entry-level role readiness (SOC, IT, GRC)

---
